# Support

If you need help getting the game running, or have questions about the underlying OpenGameStack AI template, please check the following resources:

1.  **README:** Start by reading the `README.md` file for setup instructions via the OGS Launcher.
2.  **Issues:** Search the Issues to see if someone else has already reported your problem.
3.  **Create an Issue:** If you can't find an answer, please open a new issue. Be sure to provide your OS, Godot version, and OGS Launcher version.

Please note that this is an open-source project maintained by volunteers (and AI agents), so response times may vary.
